# Recruitment Assignments Portfolio

Welcome to my portfolio of technical assignments completed for various recruitment processes. Each project demonstrates a different set of skills, technologies, and architectural patterns.

## 📂 Projects Overview

### 1. [ArvyaX AI Journal System](./ArvyaX)
An AI-assisted wellness journaling application.
- **Tech Stack:** Next.js, MongoDB, Gemini AI, Tailwind CSS, Framer Motion.
- **Key Features:** Emotional analysis of journal entries, nature-themed reflections, and interactive insight dashboards.

### 2. [She Can Foundation - Contact Portal](./She_Can)
A high-performance contact management system and landing page.
- **Tech Stack:** Next.js 15, Tailwind CSS v4, Zod, React Hook Form.
- **Key Features:** Stunning glassmorphism UI, robust form validation, and modern responsive design.

### 3. [Rayeva AI Backend System](./Rayeva%20–%20AI%20Systems%20Assignment)
A production-ready backend following clean architecture principles for AI-integrated commerce.
- **Tech Stack:** Node.js, Express, MongoDB, AI Prompt Engineering.
- **Key Features:** Clean architecture (Controller -> Service -> AI Service), sustainable commerce workflows, and structured logging.

### 4. [Celebrare Photo Gallery](./Celebrare-photo-gallery)
A sleek and responsive image gallery.
- **Tech Stack:** React, Vite, Tailwind CSS, Picsum API.
- **Key Features:** Dynamic photo fetching, real-time search, and a persistent favorites system (Local Storage).

### 5. [Assignment-1](./assignment-1)
A responsive web application project.
- **Tech Stack:** Next.js, Tailwind CSS.
- **Key Features:** Hero sections, scroll animations, and structured layout components.

### 6. [Eduminatti](./Eduminatti)
A foundational Node.js server implementation.
- **Tech Stack:** Node.js, Express.
- **Key Features:** Backend routing and server-side logic setup.

## 🛠️ General Tech Stack

Across these assignments, I have utilized:
- **Frontend:** React, Next.js (App Router), Tailwind CSS, Framer Motion, Vite.
- **Backend:** Node.js, Express, MongoDB (Mongoose).
- **AI/ML:** Google Gemini AI integration, Prompt Engineering.
- **Tools:** TypeScript, Zod, NPM/Yarn.

## 🚀 How to Run
Each directory contains its own `README.md` with specific instructions. Generally:
1. Navigate to the project directory: `cd project-name`
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev` (or `npm start`)
